# Security Policy

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| 0.x     | :white_check_mark: |

## Reporting a vulnerability

This project does not handle real money, authentication, or user data beyond
what the user voluntarily saves in their own browser (LocalStorage).

If you find a security issue nonetheless, please open a GitHub issue
with the label `security` or contact the repository owner directly.

Do **not** open a public issue for critical vulnerabilities — send a
private message to `@PabloGonSan8` instead.
